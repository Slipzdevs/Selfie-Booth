# Selfie Booth

A browser-based photo booth with filters, stickers, photo-strip layouts, and a local gallery.

Photos and gallery strips stay in the current browser on your device. The app does not offer phone sharing or QR downloads. Existing temporary download links created before this change remain available until they expire.

## Run locally

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.

Camera access requires HTTPS or localhost.

## Build

Run `npm run build` to type-check and create the production build in `dist/`.
